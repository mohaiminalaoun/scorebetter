# ScoreBetter

## Code style

- Comments are at most 2 lines. If an explanation needs more, it belongs in a
  doc under `plans/`, not in the source.
- Comment on *why*, not *what*. Skip comments that restate the code.

## Commits

- Commit messages are one line. No body, no bullet list.
- Commits are attributed to the repo owner only. Do not add Claude/AI
  co-author trailers, "Generated with" lines, or session links.
